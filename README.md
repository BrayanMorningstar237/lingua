# Langwa

Langwa shows digital banking pages in Cameroon's national languages(traditional), without changing the
bank's code. Amounts, fees, beneficiaries, account numbers and references are protected: they
are never translated, never sent anywhere, and every translation is checked against them
before it is shown.

```
browser-extension/        the extension (no build step, no dependencies)
  manifest.json
  src/protect.js          detects and protects financial values, integrity check
  src/engine.js           glossary, templates, "label : value", safe summary
  src/speech.js           listen button: human recordings + exact amounts
  src/content.js          reads the page, Ctrl+hover / long press card, panel, alerts
  src/background.js       language packs, optional local open-source translation and voice
  src/standalone.js       runtime used by the phone version (userscript)
  src/options.*           glossary editor for native speakers (recording, validation, test bench)
  src/popup.*             on/off per site, language, display mode
  lang/source.json        French/English source strings with context notes for translators
  lang/languages.json     supported languages
  lang/<code>.json        translations per language (ewo, fub, dua, bbj, bas)
  icons/                  extension icons
  tests/                  node --test tests/
tools/build.mjs           builds dist/ (zip, xpi, userscript)
server/                   optional local translation, MMS-TTS and Africa TTS voices
docs/TECHNICAL.md         technical document for the jury
```

## Get it on any browser

Build once: `node tools/build.mjs` (Node 18 or newer). This creates `dist/`.

| Browser | How |
|---|---|
| **Chrome, Edge, Brave, Opera** (computer) | Open `chrome://extensions` (or `edge://extensions`), turn on **Developer mode**, click **Load unpacked**, choose the `browser-extension` folder. To give it to anyone with one click, upload `dist/langwa-chromium.zip` to the Chrome Web Store or Edge Add-ons. |
| **Firefox** (computer) | `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → choose `dist/langwa-firefox.xpi` (Firefox has its own manifest, generated by the build; the `browser-extension` folder is the Chrome/Edge version). Then in `about:addons` → Langwa → Permissions, allow the sites. For a permanent install, sign `dist/langwa-firefox.xpi` on addons.mozilla.org (free, automated). |
| **Firefox for Android** | Publish the signed xpi on addons.mozilla.org, then install it from there on the phone. |
| **Any phone browser** (Android Chrome, Samsung Internet, iPhone Safari) | These browsers do not run extensions. Install a userscript manager: **Tampermonkey** or **Violentmonkey** (Android), or the free **Userscripts** app (iPhone, Safari). Then open `dist/langwa.user.js` and confirm the install. |
| **Safari** (Mac) | `xcrun safari-web-extension-converter browser-extension/`, then build the generated Xcode project. |

The extension is active on `safinum.cm`, `localhost` and `127.0.0.1` by default. On another
site, click the icon and turn on **Actif sur ce site**. The userscript runs on the same sites;
add others in the userscript manager (User matches).

## Using it

- **Computer:** hold **Ctrl** (Cmd on Mac) and point at any text, paragraph or button. It is outlined and its translation appears just below it. Release Ctrl to click 🔊 and listen.
- **Phone:** **long press** any text. The card appears below it. A long press never activates the bank's button.
- **Panel:** the round button at the bottom right, or `Alt+Shift+M`. The whole page, important messages first. The language can be switched at the top.
- **Translate the whole page:** `Alt+Shift+T`, or the big button in the popup. Each text is covered by its translation in the page's own font and colours; the bank's buttons keep working.
- **Listen:** the **Écouter** button on every translation. Human recordings first; otherwise the device voice, coached to read the language (labelled "Voix de synthèse"). `Alt+Shift+L` reads the whole page aloud, important messages first. While pointing with Ctrl, press **Space** to hear that text (`Ctrl+Space`, again to stop). Turn on **Lecture automatique** in the popup to hear each card as soon as it opens.
- **Assistant tab:** ask about the page in your language ("How much I go pay?", "Moye jaɓata ceede ɗee?"). Built-in answers are instant, offline and use the page's own amounts. Free questions use a local open-source model (Ollama) if set up. Voice questions: the browser's speech recognition with consent (French, English, Pidgin), or `python server/asr_server.py` (Meta MMS, detects the language, all languages).
- **New messages:** any new error, warning or confirmation pops up translated, and is read aloud when a recording exists.
- On first use, a short visual hint shows the gesture.

## Filling in a language (the native speaker's job)

1. Open the extension's options (popup → **Glossaire, voix et paramètres**).
2. Choose the language and type the validator's name.
3. For each line: write the **meaning** (as you would explain it to a relative), tick **Validé**, and record your voice.
   - Context notes under the French text explain what each banking term really means.
   - `{amount}`, `{name}`, `{count}` must stay: the editor refuses to validate otherwise.
   - For sentences with values, record each piece. The real amount and name are read in between.
   - Optional: a one-line explanation of a difficult word. It is shown under the translation.
4. Lines marked **À vérifier sur la vraie page** were copied from an auto-translated view of the test page. Compare them with the real page (browser translation turned off) and fix `lang/source.json` if needed.
5. **Exporter le fichier de langue** → save it as `browser-extension/lang/<code>.json`, then run `node tools/build.mjs`.

The **banc d'essai** (test bench) shows, for any sentence, what is protected, what would leave
the page, the result, the integrity check, and lets you hear it.

## Getting translations from speakers (no install needed)

1. Run `node tools/build.mjs`. It creates `dist/langwa-collect.html`, a one-file contribution page.
2. Send that file on WhatsApp, or host it: with GitHub Pages enabled, it is at `https://<user>.github.io/<repo>/collect/`.
3. The speaker opens it on a phone, chooses the language, and translates one sentence per screen, starting with the test journey. They can record their voice, tap dictionary suggestions, and stop and continue later (everything is saved on the phone).
4. **Envoyer mes traductions** shares a small file directly to WhatsApp (or downloads it).
5. The team opens the glossary editor → **Importer (JSON, CSV)** and selects one or several received files. New translations are added as "Non validé"; validated ones are never overwritten.

### Lamnso' (Nso) local translation draft

Lamnso translation runs entirely on this computer with one launcher: `server\start-lamnso.cmd`. The first run downloads llama.cpp for CPU (about 20 MB) and Qwen2.5-1.5B-Instruct (about 1.1 GB, Apache-2.0), then starts the corpus retriever (port 8769) and the model (port 8771, about 1.2 GB of RAM, one request at a time). Langwa uses them automatically for Lamnso only; no Options change is needed, and a different local LLM can still be chosen there. For each sentence the extension retrieves up to three similar English or French to Lamnso Bible pairs and the Lamnso dictionary words found in the sentence, and gives them to the model as language hints. Amounts, names, numbers and account identifiers stay masked until the result passes integrity checks. Results are cached, so each sentence is translated once.

The corpus contains Bible-derived text, not banking or conversational translations. It is used as translation context only and is never shown directly to the user. All output remains an experimental, unvalidated draft; have Lamnso speakers review financial and safety wording. Corpus licensing and preparation details are in [docs/lamnso-corpus.md](docs/lamnso-corpus.md). The builder code is MIT licensed, while the underlying YouVersion text has third-party terms. The older MarianMT fallback remains available for experiments but is not used for Safinum banking content because its output was unreliable.

The optional `server/cameroon_mt_server.py` uses Flagship AI's int8 French-pivot MarianMT routes for English/French to Lamnso'. Start it with the packages in `server/requirements-cameroon-mt.txt`; it downloads just the English→French and French→Lamnso' model folders on first use. In Options, select the Cameroon MT mode and translate the page. Drafts remain unvalidated and values stay protected. The model is CC BY-NC 4.0, so this route is for non-commercial use unless separate permission is obtained. The available Lamnso' Bible corpus is a parallel-text research resource, not a source of banking terminology or validated financial translations.
6. A second speaker (or the same one, re-reading) ticks **Validé** with their name.

Teams that prefer a spreadsheet can use **Tableur (CSV)** to get every phrase in Google Sheets or Excel, fill the `translation` column, and import the CSV back.

**Dictionary suggestions** come from `node tools/harvest-wiktionary.mjs`, which collects openly licensed terms (Wiktionnaire, CC BY-SA 4.0) into `data/terms.json`. They are hints for speakers, never shown to users as translations.

## Optional local open-source helpers

Without them, sentences that are not in the glossary get a **safe summary**: a validated
sentence for the message type, validated key words, and the exact amounts.

- **Translation:** Ollama with an open model (e.g. `qwen2.5:7b-instruct`, Apache-2.0), started with `OLLAMA_ORIGINS=* ollama serve`; or `python server/nllb_server.py` (NLLB-200 supports Fulfulde, Ewondo, Duala, and Basaá in this project). Choose it in the options. The local model gets French and English source text plus glossary meaning notes, while protected values stay masked.
- **Voice:** download **langwa-voice.zip** from the website (a few KB), unzip it and double-click **Start Langwa voice.cmd**; from this repository, double-click **server/start-voice.cmd** (Mac/Linux: `sh server/start-voice.sh`). Nothing needs to be installed first: if the computer has no Python, the launcher fetches [uv](https://github.com/astral-sh/uv) (MIT/Apache-2.0), which places a private Python inside the Langwa folder, without admin rights. The first time it installs Africa TTS and downloads the voice model (about 700 MB in all, resumes after a dropped connection), then asks once whether to start the voice with the computer. After that the voice is ready in about 20 s. Langwa finds it automatically (voice setting **Automatique**) and uses the browser voice until it is ready. Trained for Ewondo, Duala and Basaá; Pidgin is read with Krio (the closest trained creole, chosen by ear over the English voice); experimental for the other languages. The model is too large to ship inside the extension (10 MB limit; the browser version alone is about 390 MB), so it runs beside the browser, on this computer, offline. Light on memory: the transformer runs in int8 (Kyutai's recommended setting; faster, the audio decoder stays full precision) and the model lives in a worker process that sleeps after 10 minutes without use on computers with 8 GB of RAM or less (60 minutes otherwise; `--idle`), giving all its memory back. Opening a bank page wakes it in about 20 s; phrases already heard play instantly even while it sleeps. Use `--full-precision` to turn int8 off. Model and voices: CC-BY-NC-4.0.
