Gratuit, sans compte. S’installe à la main en attendant les boutiques des navigateurs.

Recommandé pour vous

Chrome, Edge, Brave, Opera

  1. Téléchargez le fichier, puis clic droit et « Extraire tout ».
  2. Ouvrez chrome://extensions (Edge : edge://extensions) et activez le mode développeur.
  3. Cliquez sur « Charger l’extension non empaquetée » et choisissez le dossier langwa-chromium extrait.

Recommandé pour vous

Firefox

  1. Téléchargez le fichier Firefox (.xpi).
  2. Ouvrez about:debugging, puis « Ce Firefox ».
  3. « Charger un module temporaire » et choisissez le fichier .xpi.

Téléphone

Vous utilisez Chrome sur Android Chrome sur téléphone ne peut pas ajouter Langwa (Google n’y autorise pas les modules). Installez le navigateur gratuit Firefox, ouvrez cette page dans Firefox, puis suivez les étapes ci-dessous. Installer Firefox (gratuit)
  1. D’abord, l’app d’aide gratuite (une fois) : Android : Tampermonkey dans Firefox iPhone : app Userscripts (Safari)
  2. Puis touchez « Installer Langwa » ci-dessous : l’app vous demande de confirmer.
  3. Sur la page de votre banque, appuyez longuement sur un texte.

Voix naturelle (option)

Ordinateur : Windows, Mac, Linux
  1. Téléchargez et décompressez le fichier.
  2. Double-cliquez sur « Start Langwa voice ». Aucune fenêtre : une page de progression s’ouvre dans le navigateur.
  3. La première fois, environ 700 Mo sont téléchargés une seule fois, avec la progression en direct. Langwa lit alors en pidgin, fulfulde, ewondo, duala, basaá et d’autres.
Télécharger la voix Déjà téléchargée ? Double-cliquez à nouveau sur « Start Langwa voice » : elle démarre en 20 secondes environ.
Ensuite, ouvrez la page de votre banque et choisissez votre langue. Un court guide vous fait le tour.
